# Business Review Reply AI — Chrome extension

Manifest V3 extension for generating editable AI replies to customer reviews shown in Google Maps or Google Business Profile.

## Local test

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Choose **Load unpacked** and select this `extension` directory.
4. Open a review in Google Maps or Business Profile and open the extension.

The extension never publishes a reply automatically. It only inserts the generated text into the visible reply field so the user can review and submit it.

## Chrome Web Store

Zip the contents of this directory (with `manifest.json` at the ZIP root). Use the public privacy policy at https://googlereviewai.com/privacy.
